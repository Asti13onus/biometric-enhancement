# Correspondence

Drafted data-access requests. **Nothing here has been sent** — each file's header records
the send date once it goes out, and `docs/datasets/REGISTRY.md` is the master status table.

Send from your **institutional address**, not a personal one. Every one of these is reviewed
by a human whose main signal is that you are a real researcher at a real institution.

Everything else has a workaround already in hand, which is why they are below it.

## Rules for all of them

- **One thread per request.** Reply into the same thread when chasing, so the history is
  visible to whoever picks it up.
- **Cc your supervisor.** For IAB specifically, a supervisor-to-supervisor email to
  Prof. Vatsa or Prof. Singh moves faster than a form — the thesis plan says so explicitly.
- **Log the send date** in `REGISTRY.md` immediately. The week-4 chase trigger depends on it.
- **Save every licence PDF** into `docs/datasets/licences/` when it arrives. We need the
  exact citation and redistribution terms later, and reconstructing them at write-up is
  painful.
- Do not promise anything about redistribution. Several of these licences forbid it, and
  Contribution 3 is designed to release *split files and scripts*, never images.
